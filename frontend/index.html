ABOUT

How LeafGuard AI Works

An end-to-end AI web application built around a 38-class plant-health image classifier.

01

Validate

Checks file type, size, dimensions, brightness, blur and a lightweight plant/non-plant gate before classification.

02

Predict

The fine-tuned MobileNetV2 image classifier predicts among 38 supported plant-health classes across 14 crop species.

03

Explain

For confident predictions, Grad-CAM highlights the image region that most influenced the CNN prediction.

04

Guide

Shows symptoms, prevention and general treatment guidance with an uncertainty warning when needed.

05

Remember

Prediction history, statistics and uploaded images are stored per user in PostgreSQL.

06

Secure access

Users can register and sign in with JWT sessions. Passwords are stored as salted PBKDF2 hashes.

⚠️ Production deployments should use a strong secret key, HTTPS, a production database, rate limiting and a proper agricultural validation process.
